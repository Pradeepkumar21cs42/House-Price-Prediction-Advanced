\# House Price Prediction - Advanced



\## Project Overview

This project predicts house sale prices using Machine Learning algorithms based on property features, quality, size, and location.



\## Objective

To build a Machine Learning model that accurately predicts residential house prices and deploys the model using Streamlit.



\## Dataset

\- Dataset: House Prices Dataset

\- Total Records: 1460

\- Target Variable: SalePrice



\## Technologies Used

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Scikit-learn

\- Streamlit

\- Joblib

\- Jupyter Notebook



\## Machine Learning Algorithms

1\. Linear Regression

2\. Ridge Regression

3\. Random Forest Regressor

4\. Gradient Boosting Regressor



\## Best Model

Gradient Boosting Regressor

